CSV Data Processor

A Python automation project that reads sales data from a CSV file, processes product information, calculates sales
statistics, and generates a report.


Features

- Reads sales data using CSV
- Calculates total sales
- Calculates total quantity sold
- Finds the best-selling product
- Calculates average sales
- Generates average sales
- Supports adding new products without changing the python code


Technologies

- Python
- CSV module
- Functions
- Lists and Dictionaries
- Lambda and Sorted


Project Files

- csv-processor.py-Main python program
- sales.csv-Sales data
- sales_report.txt-Generated report


How to Run

1. Make sure Python is installed
  
2. Run:
   python csv_processor.py
   
3.The program reads the CSV file and generates a sales report.


Purpose

This project was created to practice Python automation, CSV data processing, and report generation.
